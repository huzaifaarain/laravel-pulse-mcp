## Installation

You can install the package via Composer:

```bash
composer require huzaifaarain/laravel-pulse-mcp
```

You may publish all the package's resources at once with:

```bash
php artisan vendor:publish --tag="laravel-pulse-mcp"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="laravel-pulse-mcp-config"
```
